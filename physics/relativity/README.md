# 理论测量的边界（版本 1.0）

一本关于**测量、对称与理论结构**的理论物理书稿。全书以「恒速群 $G_K$」为轴：把不变速度写成一个可取不同数值的参数 $K$，于是洛伦兹变换（$K=c$）、伽利略变换（$K=\infty$）与 Carroll 极限（$K=0$）成为同一族结构的三个取值；书稿逐一考察在每一支下，哪些结论随 $K$ 改变、哪些不变。

- **作者**：杨国梁（山东 济南）
- **版本**：1.0
- **排版**：Quarto book + XeLaTeX（ctexbook），A4，中文正文
- **成品**：`_book/理论测量的边界.pdf`

## 一、这本书在做什么

全书只追问一件事：**一个物理结论，究竟来自被研究的对象，还是来自我们用来描述它的那套坐标与配对规则。**

为此书稿把「测量」拆成可分别检验的几层：

| 层次 | 内容 | 随参考系变吗 |
|------|------|------|
| 事件与钟面读数 | 某只钟在某个事件上显示的数字 | 不随任何描述而变 |
| 配对（同时）规则 | 把谁的事件与谁的事件放在一起比较 | **随结构与约定而变** |
| 变换公式与坐标量 | 洛伦兹/伽利略变换给出的坐标时、投影时 | 随结构而变 |

书稿的立场是：**把三层的结论分开列，各自标明依据；不把配对层的差别说成对象层的差别。** 第 13 章《再论对称双生子》是这一方法最完整的演示。

## 三、书稿的几个特点

1. **可对照的数字。** 同一个问题（"A 走一秒时 B 走多少"）分别只用对称、只用洛伦兹变换、只用伽利略变换各算一遍，三个答案并排（第 13 章表 13.1）。
2. **符号计算与正文同源。** 各章的闭式（Ricci、Weyl、中央扩张、双生子比值等）由 `chapters/images/*.py` 用 sympy 逐项得出，脚本输出与正文结论一一对应；改公式须同步改脚本。
3. **两支并列，不作评判。** 第 13 章把地球版双生子分别放进 $K=c$ 与 $K=\infty$，各列其公理、各推其结果，并列摆放，不评判孰是孰非。

## 四、构建

### 依赖

- [Quarto](https://quarto.org)（≥ 1.4）
- TeX 发行版（TinyTeX 或 TeX Live），需含 `xelatex` 与 `ctex` 宏包
- Python 3.13（仅用于生成配图），需 `sympy`、`matplotlib`、`numpy`

### 命令

```bash
# 生成 PDF（输出到 _book/）
quarto render --to pdf

# 生成 HTML
quarto render --to html
```

### 配图

配图脚本位于 `chapters/images/`，脚本与输出图同名：

```bash
cd chapters/images
python twins-earth-two-branches.py      # 生成 twins-earth-two-branches.png
```

每个脚本开头都有一段 sympy 符号核验，会把关键等式打印到标准输出（例如 `gamma(K) = 1/sqrt(1 - v**2/K**2)`、`K -> oo : 1`）。

### 目录要点

```
_quarto.yml            书籍配置（章节顺序、定理环境中文名、格式）
preamble.tex           LaTeX 导言区（书名命令、版式、页眉页脚）
before-body.tex        自定义封面（含版本号）
chapters/*.qmd         正文各章
chapters/images/*.py   配图脚本（含符号核验）
chapters/references.bib  参考文献库
_deliver/              单行本（可独立渲染的单章）
```

## 五、体例约定

- 定理类环境按章连续编号：公理、定义、命题、定理、引理、推论。
- 公式按章连续编号，交叉引用使用超链接，不写手写式号。
- 证明结束不另加结束符号。
- 符号冲突与多重含义统一登记在「符号与约定」一章（尤其 $K$、$h$、$c$ 的角色）。
