## 1 文件与构建管线

### 1.1 目录结构

| 位置 | 内容 |
|------------------|----------------------------------|
| `index.qmd` | 前言（root，含作者注、时间、体例声明） |
| `chapters/*.qmd` | 编号章与无编号章（导览、符号与约定、参考文献、关键词索引） |
| `chapters/images/` | 全部配图 PNG 与同名生成脚本 `.py` |
| `chapters/references.bib` | 文献库 |
| `csl/` | GB/T 7714-2015（numeric）样式 |
| `preamble.tex` | LaTeX 宏：目录、图目录、表目录、caption、行距、DOI 断行补丁 |
| `before-body.tex` | 封面（书名、日期） |
| `tools/` | 索引生成、章号动态化、措辞与标点体检、证明段与数值核验等脚本 |
| `_quarto.yml` | 书稿配置：章序、格式、语言、交叉引用标签 |

- 目录名与文件名用小写英文与连字符，不用空格与中文；中文只出现在标题与正文。
- 备份、临时产物不入版本库（写入 `.gitignore`），也不在正文里指向它们。

### 1.2 渲染与收敛

```bash
# 在项目根执行；QUARTO 为 quarto 可执行文件（已在 PATH 时省去前缀）
QUARTO render --to pdf

# 正文页码变动后：重建索引 → 再渲染一次
python tools/build_index.py
```

- `quarto` 不保证在 PATH 中。临时使用时可把其 `bin` 目录前置；Windows 的 sh 环境需保证 `PATHEXT` 含 `.EXE`、`.CMD`，否则 quarto 调用外部程序会静默失败。
- 渲染脚本、配图脚本、体检脚本使用**同一个** Python 解释器；解释器路径由环境变量或项目说明统一给出，不在本文各命令里重复写死。
- **质量判据**（全部满足才算通过）：渲染日志含 `Output created` 且无 `warning`、`error`、`overfull`、`Unable to resolve`；PDF 文本中 `@sec-`、`@eq-`、`@tbl-`、`@fig-`、定理类前缀的残留为 0；索引两次生成 sha 一致（输出 `CONVERGED`）。
- 后台日志里 `reg.exe 被安全策略拦截` 属渲染器的无关内部调用，`grep` 零匹配导致的退出码 1 属正常，二者都不判为失败。

### 1.3 中文渲染的前置条件

- **渲染链必须显式指定含 CJK 字形的字体**。缺省拉丁字体下汉字整篇不出字形，页面上只剩西文与数字，表格两列还会挤到一处，观感即“乱码”。PDF 元数据里字体只有 Latin Modern 一类，便是此症。
- **字体经模板变量注入，不经格式顶层键**：文档头写 `format.typst.variables.mainfont`（正文字体）与 `format.typst.variables.codefont`（等宽且含 CJK 的字体）；直接写在这一层的 `font` 会被丢弃。字体名写**单个字符串**，写数组会被拼成一个不存在的名字（`["A","B"]` 变成 `AB`），回退只能靠字形逐字回退。
- **判定方法**：抽取 PDF 文本，统计汉字个数；`0` 即字体链未生效。计数只验存在性，不验字形正确性，字形仍需目视。
- **表格列宽**由分隔行的破折号长度按比例决定。分隔行长短悬殊（如首列 3 个、次列百余个）会把首列压到百分之一量级，文字相互叠压；分隔行按内容比例书写，或全列等长以交给自动排版。
- 文内引用标记若要作为**示例字面**出现，必须放进行内代码（`` `@fig-x` ``）。裸写会被解析为交叉引用，轻则告警，重则中断编译。

## 2 章与文件结构

### 2.1 章文件格式

- **首行**必须是章标题行 `# 章题 {#sec-…}`，前面不留空行；行尾为 LF（禁 CRLF）。
- **章标题锚点**：编号章带 `{#sec-<英文名>}`；无编号章带 `{.unnumbered}`（参考文献、索引）或 `{.unnumbered #sec-…}`（导览、符号与约定）。
- **章序**以 `_quarto.yml` 的 `chapters:` 列表为准，文件名即章名来源；正文**禁止硬编码章号**（`第 N 章`），一律用 `@sec-…` 动态引用。唯一例外：由脚本生成的索引页。
- **无编号章不可被 `@sec-` 交叉引用**（其小节渲染为 `\section*`，不生成引用目标）；指向它们一律用纯文字（如“符号与约定”中 $K$ 的条目、“全书导览”的某一节）。

### 2.2 章内部体例

- **章首**：开头有相关说明文字。
- **无编号章**（导览、符号与约定）内的条目以表格登记，不参与章编号。

## 3 标题层级与过渡

- 层级用 `#`（章）、`##`（节）、`###`（小节）；可用 `####`。
- **`##` 与其后第一个 `###` 之间必须有过渡文字**。禁两种极端：标题直接贴标题；复读标题的空话导语。
- **标题尽量不用标点和空格**：冒号、逗号、破折号、括号和空格尽量不入标题，其余改写为名词短语或无标点短句。标题内尽量少用数学表达式；标题末不带标点。
- **定理类环境的标题只用纯文字**：粗体定理头字体缺希腊字形，标题里的 $\psi$ 等数学符号渲染为缺字。
- **标题措辞**：覆盖本节实际内容，简洁明了，不得以偏概全。

## 4 公理块与证明段

### 4.1 公理块（cnj 环境）

````
::: {#cnj-<名字>}
## <短标题>（<可选简称>）
<公理的纯陈述>
:::
````

- 环境自动渲染编号“公理 N.M”（由 `_quarto.yml` 的 `crossref-cnj-title: "公理"` 决定），**标题里不写“公理”二字**（如“传播律（A1）”，非“传播律（公理 A1）”）。
- **块内只放公理本体**：代入判据、例子、形式条件（如“若 $t=0$ 则 $t'=0$”）移到块后说明段；正文引用公理时用渲染后的编号（“由公理 1.3，$t=0\Rightarrow t'=0$”）。
- **术语统一为“公理”**：正文、标题、脚本注释、README 不用“公设”；“假设”一词保留给合法语境（外加假设、反证假设、结构假设 (S)、物质侧假设），不作公理的称呼。
- 公理清单若为散文式带标签清单，保持散文形态并在其后登记“与前面公理的对应”式对应表；不强行改成编号块（引用结构不同）。

### 4.2 证明段（Halmos 符号）

- 证明段以 `**证明**` 起首（可带括号副题：`**证明（分四步）**`；证明概要单列时用 `**证明要点**`）。**头部不加句点**：写 `**证明**`，不写 `**证明.**`——句点的职责交给结束符。
- **每个证明段必须以 Halmos 符号 □ 收束**，写 `$\quad\square$`（空心方块，AMS 默认 `\qedsymbol` 同形；PDF 与 HTML/KaTeX 双格式均支持）。禁用：`证毕`、`$\blacksquare$`（实心，易与“例题结束”类记号混淆）、U+220E 空心方块字符、`QED`。
- 落点三则：
    - 正文句收尾：句末标点后接 `$\quad\square$`（`……不成立。$\quad\square$`）；
    - 显示公式收尾：公式末行句末标点后接 `\quad\square`（块内，与公式末标点规则相容）；
    - 代码块或表格收尾：`$\square$` 单独成段置于其后。
- □ 只作结束记号，不参与句子语法：它之前的最后一个字符必须是句末标点。
- 机器检查：`tools/check_proof.py`；批量修补用幂等脚本，改前先跑一遍 dry-run。

## 5 交叉引用

### 5.1 命名习惯

`sec-` 用章文件词干；`eq-` 用章缩写＋名称（如 `eq-ifg-R`）；被引用的对象才需要标签，不预留空标签。

### 5.2 引用写法与冗余禁令

- **章级**：写 `@sec-x 章`，渲染为“第 N 章”——源文的“章”正好补齐，不算冗余。
- **节级**：渲染为“小节 N.M”，源文**不得**再加“一节”“小节”等量词（禁“小节 2.8.3 一节”）。
- 公式引用写“代入式 1.3”（`@eq-lin-x`）；图表引用写 `@fig-x`、`@tbl-x`，由渲染器自动带“图 N”“表 N”。
- **纯指代性完整重写改交叉引用**（“代入 $x'=Ct+Dx$”改为“代入式 1.3”）；**推导变形保留原式**（公式代入后有改动，如 $0=Ct+D(vt)$，换引用反而读不懂）。
- 检查：渲染后 PDF 文本检索 `@sec-`、`@eq-`、`@fig-`、`@tbl-` 等前缀，应为 0。

## 6 术语纪律

### 6.1 命名规范（正名表）

| 采用 | 禁用或旧名 | 说明 |
|----------------|--------------|--------------------------|
| 公理 | 公设、（公理语境下的）假设 | 编号环境与正文一致 |
| 参与方 | 观者、观察者、观测者 | 全书唯一称谓；“输出与参与方无关”等定理名同此 |
| 线长 $s[\gamma]$、读数 $\tau$ | 固有时 | 两记号定义独立，不预设相等；“线长等于读数”只是外加输入 (P3b)，全书不采用 |
| 变换因子 $\gamma$ | 钟慢因子 | $K=\infty$ 支不用“洛伦兹因子”名 |
| 恒速群 $G_K$ → 恒速场 $K(p)$ → **恒速群丛** | 恒速场群 | 群丛是丛不是群，名字末字“丛”须如实 |
| Newton–Cartan 几何 | — | 只登记已构造，不称原创 |

### 6.2 禁词表（中性措辞）

描述两支（$K=c$ 与 $K=\infty$）不用带倾向的词：**禁**“退化”“塌缩”“失败”“无意义”“给不起”“盲区”“说不出口”。改法：只写可核对事实（秩由 4 变 1、$dx^2/K^2$ 项为零、度规不可逆、极限时不保持）。工具：`tools/neutralize_terms.py`。

### 6.3 态度句纪律

洛伦兹变换对错**不表态**；删除“既不预设”“刻意”“不是遗漏”“不采用也不否认”类表态句（不写就是态度）；快慢判定只写**写明配对的相对比值**（A 与 B 之间比值 1；各自与地球比 $1/\gamma_v$），禁不带配对的“绝对变慢”。

### 6.4 标签括号

结构标签一律**半角括号**：`(M1)—(M4)`、`(P1)—(P4)`、`(P3a)`、`(P3b)`、`(A1)—(A4)`、`(S)`、`(L)`、`(G)`；标题不用修饰性括注（见 §3）。单破折号 `—` 兼作范围连接号与表格空位符（见 §8.2）。

### 6.5 口语化表述

保持学术专著措辞：**禁**“归堆”“走不通”“免费的”“摆在桌面上”“让它替…去…”类口语，改写为可核对的书面表述（“分组”“不可行”“无需额外构造”“可直接对照”“由它代替…进行…”）。“记账”“账本”作为 bookkeeping 的既定译法保留。朴素词纪律（格子、读数、尺子、路径，术语括注一次）不变——朴素指用词常见，不指句式随意。

## 7 数学与公式

- 行内数学 `$…$`；编号公式：

  ````
  $$
  …公式体…
  $$ {#eq-<名>}
  ````

- **项顺序统一 $(t,x,y,z)$**：变换式 $t$ 项在前、横向项在后。
- **事件坐标元组一律 $(t,x)$**：正文与配图标注中的时空点（如 $P$、$Q$、$M$）都按 $t$ 在前书写（如 $M=(d/v,\,0)$），不用 $(x,t)$ 的“横纵”习惯次序。
- 三维向量用 `\mathbf{}` 粗正体；时间一形式记 $n_\mu$（NC 表），避免与读数 $\tau$ 冲突。
- $K$ 与速度同量纲 $[K]=LT^{-1}$；几何单位 $c=1$ 时的 lapse 写法（两种相差单位换算，不改比值结论）；$K(p)$ 是标量函数，非密度、非度规或联络分量——身份登记见符号章的“单位制、量纲与规范身份”。
- 编号公式新增后：检查正文中的纯指代性重写是否应改为交叉引用（§5.2）。

### 7.1 数学符号体例（与国际惯例对齐）

**判据**：以 ISO 80000-2 与主流相对论教材（MTW、Wald、Carroll）的写法为准；**一个符号全书只允许一种写法**。

| 项 | 体例 | 例 |
|------------|----------------------------|------------------|
| 三维向量（拉丁字母） | `\mathbf` 粗正体 | $\mathbf{x}$、$\mathbf{E}$ |
| 希腊字母向量 | `\boldsymbol`（`\mathbf` 对希腊字母在 unicode-math 下直接丢失） | $\boldsymbol{\xi}$ |
| nabla | 一律不加粗，写裸 `\nabla`；禁 `\vec\nabla`、`\boldsymbol{\nabla}` | $\nabla\cdot\mathbf{E}$ |
| 微分 | `\mathrm{d}`，含 $\mathrm{d}^{3}x$、$\frac{\mathrm{d}}{\mathrm{d}t}$ | $\mathrm{d}s^{2}$ |
| 虚数单位 | 斜体 `i`；禁 `\mathrm{i}`（与空间指标 $i$ 靠上下文区分） | $e^{i\theta}$ |
| 希腊字形 | `\varepsilon`（禁 `\epsilon`）；`\phi` 与 `\varphi` 按对象分工 | $\varepsilon_{0}$ |
| 张量指标 | 一上多下用错位指标 `{}_{}`；禁 `_{\ \ }` 手动空格 | $\Gamma^{\lambda}{}_{\mu\nu}$ |
| 算子名 | `\operatorname{...}` 正体 | $\operatorname{supp}$ |

- 度规签名全书 $\eta=\mathrm{diag}(1,-1,-1,-1)$，声明见符号章“全局约定”。
- **为什么 nabla 不加粗**：`\symbf` 虽能让拉丁与希腊字母同时出粗正体，但 HTML 格式（KaTeX）不支持；`\boldsymbol{\nabla}` 在 Latin Modern Math 下不粗，`\mathbf{\nabla}` 直接消失。裸 `\nabla` 是“不粗”（ISO、Griffiths、Landau）与“粗”（Jackson、MTW）两派写法中，能在本书字体与双格式管线下全程一致的一派。曾因混用 `\boldsymbol{\nabla}` 与 `\vec\nabla` 使整批公式渲染异常，批量修正后不再回退。
- 批量统一用幂等脚本（先 `--dry` 看差异，再落盘）；回归检查用 `tools/check_symbols.py`。

### 7.2 数值：精确值与近似值

**判据：右侧的数是不是左边算式的精确值？** 是则 `=`，否则 `\approx`。精确值指整数、有限小数、以及可精确化简的根式与分式（如 $\gamma=1/\sqrt{1-0.6^{2}}=1.25$、$2\sqrt{50^{2}-30^{2}}=80$）；四舍五入得来的十进制一律 `\approx`（如 $2\sqrt{50^{2}+30^{2}}\approx116.6$、$\ln2\approx0.693$、$w\approx0.8824c$）。

| 情形 | 写法 | 例 |
|----------------|----------|----------------------------|
| 恒等、定义、精确化简 | `=` | $\gamma_w=\dfrac{1+0.36}{1-0.36}=2.125$ |
| 四舍五入后的十进制 | `\approx` | $\dfrac{80}{2.125}\approx37.6$ |
| 无理数的截断小数 | `\approx` | $\ln2\approx0.693$ |
| 截断并用省略号（表内保持位数） | `\ldots`，可不用 `\approx` | $1.8725018\ldots$ |
| 量级估计 | `\approx` 或 `\sim` | $\sigma(\alpha_A-\alpha_B)\approx10^{-5}$ |
| 参数取值（人为设定） | `=` | 取 $v=0.6c$、$T=100$ 年 |

- **一个数只有一个身份**：精确值不写“约”，近似值不用 `=`。
- **并列数值**：同一串里只要含近似值，整串用一次 `\approx` 统摄（精确成员当然也“近似于”自身），不逐个混写“$=8.00$、$\approx19.08$”。
- **“约”与 `\approx` 不并用**：散文里写“约 $37.6$”（数字独立、不带等号）；公式里写 `\approx37.6`。禁“约 $\approx69$”这种双标记。
- **有效数字**：与输入精度相称，一般 3 至 4 位；同一个量在全书的数字固定下来，不随出现位置变化；需要与同表其它数相减时保留更多位。
- **表格不写 `\approx`**（列宽与对齐会被破坏）：改在题注末尾标“（近似值）”，表内数值统一末位四舍五入；确需显示截断的单元格用 `\ldots`。
- **每一处数值都要可复算**：算式与书中值登记进 `tools/verify_numbers.py`，脚本逐条判定精确相等、按书写位数四舍五入相符、量级相符或不相符；出现“不相符”即不得提交。新增数值时同步登记，不留“只在 PDF 里对”的数。
- **图注坐标与正文同标准**：图上标注的事件坐标、线长若与正文重复，两处必须由同一算式生成；不一致时以可复算的一侧为准，并同时改图与文。

## 8 标点符号

本节依 GB/T 15834—2011《标点符号用法》、GB/T 15835—2011《出版物上数字用法》，并结合物理学专著（编号公式、定理块、图表密集）的排版惯例制定。三条总则贯穿全节：

1. **中文行文用全角标点**，数学式、代码、URL 与 DOI、文献条目内用半角；
2. **标点随句子，不随公式**——公式是展示对象，句读由公式前后的正文承担；
3. **同一结构全书只用一种写法**，不为单处语感改体例。

### 8.1 引号

- 中文引用一律**双引号 “”**，引号内再引时用**单引号 ‘’**；**禁**直角引号 `「」` `『』`，禁半角 `"..."`（含英文直引号包中文）。
- **引号与相邻汉字之间不留空格**：写“句末说‘逐阶完备化’”，不写“句末说 ‘逐阶完备化’”。Markdown 强调符号后、列表序号后、标题 `#` 后的空格属语法要求，不计。
- **标点归属**：引文独立成句时句末标点在引号**内**；引文作句子成分时在引号**外**。
- 术语首次出现、需强调的措辞用引号；**数学式内不用引号**，确需时放进 `\text{“…”}`。
- 检查法：逐行配对计数（遇 `“` 加一、遇 `”` 减一，中途为负即反向），比正则可靠（正则会把正常相邻引号误报）。

### 8.2 破折号与连接号

- **破折号**为 `——`（两个全角破折号字符，占两字宽），表示解释、插入或转折；成对夹注时前后各一个，单用一次时只出现一处。**禁**用单个 `—`、半角 `--` 充当破折号。
- **连接号**按语义三选一，两侧均不留空格：

| 形式 | 用途 | 例 |
|---------|-----------------|-----------------------------|
| 一字线 `—` | 起止、范围、流程、对照 | `(M1)—(M4)`、`$10^{-18}$—$10^{-15}$`、`惯性—转向—惯性` |
| 短横线 `-` | 中文语境下的复合专名、并列人名 | `洛伦兹-庞加莱型` |
| 空位符 `—` | 表格首见列的占位 | §6.1 正名表的“禁用或旧名”列 |

- 英文复合名内部用 en dash `–`（`Newton–Cartan`、`Eötvös–Richter`），不译成中文连接号，也不写成半角连字符。
- 破折号**不与冒号连用**（禁 `：——`），**不与逗号连用**（禁 `，——`）。

### 8.3 括号

| 场景 | 用 | 例 |
|----------------|--------|----------------------------|
| 行文括注（补充、说明） | 全角 `（）` | `线长（两条曲线之间的映射）` |
| 结构标签、编号 | 半角 `()` | `(M1)—(M4)`、`(P3a)`、`(A1)`、`(S)` |
| 数学括注、文献年份、页码 | 半角 `()` | `$f(x)$`、`(2026)` |
| 数学式内的中文标注 | 半角定界＋`\text{}` | `$(\text{一维})$` |
| 标题中的修饰性括注 | 全角 `（）` | `洛伦兹公理（$K=c$）` |

- 括号与其前文字之间不留空格，括号内首尾不留空格：写“（见 §8.8）”，不写“（ 见 §8.8 ）”。
- **句内括注**（括注是句子的成分）括号内不加标点，句末标点放在括号外：`……（见 @sec-layers 章）。`
- **整句括注**（括注本身是完整句子）句号放在括号内。
- 嵌套不超过两层；行文括注内再括注，内层改用半角括号或改写为破折号插入语，不出现三层全角嵌套。

### 8.4 顿号、逗号、分号

- 并列的词语、短语用**顿号** `、`；并列的数值之间也用顿号（`$t=1$、$2$、`$3$`），同一处不与逗号混用。
- 中文逗号 `，`；数字千分位、函数参数、坐标元组用半角 `,`（`1,000`、`$f(x,y)$`、`$(t,x)$`）。
- **分项列举**：各项末用分号，末项用句号；若每一项本身是独立完整的句子，则各项均用句号。同一列表只用一种写法，不混排。
- 两个独立句子之间用句号，不用逗号连接（逗号连接会被读成一句）。
- 标点紧贴前文，不出现在行首；折行由渲染决定，源文只保证标点前无空格。

### 8.5 冒号

- 冒号用于总说分说、引出列举或公式、提示性话语之后：`三种情形：`、`结论如下：`。
- **判断词后不加冒号**：写“速度定义为 $v=\mathrm{d}x/\mathrm{d}t$”，不写“速度定义为：”。
- 一句只用一次冒号；冒号后不用破折号，不留空格。
- 表格题注前的 `: ` 是渲染器语法（`: 表题 {#tbl-…}`），不属正文标点，不受本节约束。

### 8.6 省略号

- 中文省略号用 `……`（六点、占两字宽）；**禁** ASCII `...`、单字符 `…`。行内代码中的 `...` 不受此限。
- 省略号后不再加逗号、句号；不与“等”“等等”连用（二者择一）。
- 数学式内的省略用 `\dots`、`\cdots`，按位置选用（`x_1,\dots,x_n`；`a_1+\cdots+a_n`）。

### 8.7 书名号与篇名

- 书名、章名、篇名、报刊名用《》（如《理论测量的边界》）；书名号内不再套书名号。
- 指称某一章时优先用动态引用（`@sec-… 章`），确需引章名时写“`@sec-…` 章《章题》”，不硬编码章号（§2.1）。
- 西文书名保留原文时不加书名号，用斜体；文献条目内的书名由 CSL 输出，不手加书名号。

### 8.8 数学公式的标点

**体例声明：本节采用国际数学出版界的通行体例，式末标点用半角。** AMS《Style Guide》要求“每个数学式按其在句中的语法地位加标点”（*Each mathematics equation reads as a clause or sentence and is punctuated accordingly.*），AIP、APS 期刊与国内多数科技期刊同此：**公式是句子的成分，按句子需要收标点**。标点形态取**半角 `.` `,` `;`**，理由三条：

1. **与数学符号同构**。公式内的一切符号（向量、算符、编号）都是 ASCII 半角；式末再嵌一个全角汉字标点，要用 `\text{}` 回退到中文字体，字重不匹配。
2. **中文科技书刊本有此传统**：公式末多用句点而少用句号——全角 `。` 在居中公式末尾分量过重，且易与右端编号挤在一起。
3. **源码干净**：`\text{。}` 每处占多个字符，全书累积即数万字符的排版噪声；`.` 一处一个字符，改、查、diff 都直观。

代价是**正文全角、式末半角**两套标点并存。这不是瑕疵，是分工：正文的句读归属中文行文，公式的句读归属数学排版，边界就是 `$…$` 与 `$$…$$`。**正文段落内绝不出现半角句读**，这一点由体检脚本守住。

**(a) 显示公式（`$$…$$`，含编号公式）**

- 每个显示公式**必须在公式末收一个半角标点**：句子在公式处结束收 `.`；句子在公式后继续收 `,`；冒号统领的并列块，块间 `,`、末块 `.`。
- **禁止 `\text{。}` 与 `\text{，}`**：全角标点不得进入数学环境（`unicode-math` 数学字体无汉字字形，须回退中文字体；MathJax 与 KaTeX 亦须 `\text{}` 包裹），源码噪声大且字形不统一。
- **标点位置分三类**，规则不同，不可混用：

| 公式形态 | 标点落点 | 例 |
|---------------------------------|------------------------|---------------------------|
| 单行公式 | 行末直接追加 | `\Delta s=T.` |
| **垂直居中**的多行环境（`aligned`、`gathered`、`alignedat`、`cases`、`split`、`array`） | **环境内最后一行行末** | `\end{cases}` 前一行的 `3\le t\le 4.` |
| 矩阵（`pmatrix`、`bmatrix`、`vmatrix`、`matrix`） | `\end{pmatrix}` **之后** | `\end{pmatrix},` |

居中环境的 `\end{…}` 位于块的垂直中线，标点写在其后会**悬在半空**（与最后一行不同基线），故必须写进环境内最后一行；矩阵的 `\end{…}` 与末行同基线，写在其后即落在末行位置，且不能插进矩阵行内（会污染单元格）。

- 标点位于右端编号**之前**（编号在 `$$ {#eq-…}` 行生成），两者不冲突。
- **例外（不加标点）**：纯记号块（无主谓结构的符号展示，如映射定义 $K:M\to(0,\infty]$）。例外必须登记，不得随手豁免。
- 公式与编号的写法固定为 `$$` 换行公式体换行 `$$ {#eq-…}`，编号不写在公式体内（§7）。
- 公式前后留空行，不把公式塞进段落中间。

**(b) 公式内部**

- 同一行并列的式子之间用**半角逗号**并以 `\qquad` 分隔：`f_i>0,\qquad f_i(0)=1`。它与**式末逗号**的区别只在位置：并列逗号**后面还有内容**，式末逗号**后面就是公式结束**。
- 条件、约束、取值范围之间用半角逗号（`$A>0,\ B\neq0$`）；不用顿号、不用中文逗号。
- **`\,` 是细空（thin space），不是逗号**——行末出现 `\,` 不算标点（体检脚本已排除）。
- `aligned` 的**推导链**（各行以 `=`、`≈` 相连）视为一个句子：行间不加标点，只在块末收一次。`gather` 与连续独立块（链式 `$$…$$ $$…$$`）按并列分句处理：块间 `,`、末块 `.`。
- `\right.`、`\end{aligned}`、`\end{cases}` 是语法符号，**不得当作句末标点**（`\right.` 末尾是句点字符，最易误判；`\right.` 后接 `.` 会写成 `\right..`，禁止）。
- `cases` 末行的行末逗号（`value, & cond,`）属内容分隔，**改句号前须确认它后面没有内容**：`value, & cond.` 可以，其后若还有 `\\` 则不可改。

**(c) 行内公式**

- 标点写在 `$…$` **之外**：写“速度为 $v$，方向沿 $x$ 轴”，不写“速度为 $v，$ 方向”。
- 行内公式与相邻汉字之间**留一个半角空格**（本书统一体例，前后对称）；公式与全角标点之间**不留空格**（`$v$，` 不写 `$v$ ，`）。行内公式跟随正文，用全角标点，与 (a) 的式末半角不冲突。
- 不用不换行空格 `U+00A0` 冒充空格：它肉眼与半角空格相同，却会让检索与替换失手。
- `$…$` 内不得出现中文标点；确需中文说明时放入 `\text{…}`，标点随中文写在 `\text{}` 内。

**(d) 引导语与衔接**

公式前的引导语三种收尾，与 (a) 的式末标点配套：

| 收尾 | 适用 | 式末标点 | 例 |
|-------------------------|----------------|----------------|---------------------------|
| 冒号 `：` | 列举、推导步骤、多式并出 | 单块 `.`；链式块间 `,`、末块 `.` | `由式 1.3 得三个分量：` |
| 判断词直连（为、是、得、即，**不加标点**） | 定义、赋值、单式给出 | `.` | `两侧长度之差为` |
| 逗号 `，` | 公式作句中插入语，其后有下文 | `,` | `由式 1.3，`＋公式＋`得……` |

- “其中”说明符号时另起一句，不接逗号（`其中 $t$ 为……`）；故其前的公式收 `.`。
- 同一句继续时必须有显式动词（代入、得、即），引导语不得以句号或无标点的名词短语收尾后直接续写。

**(e) 引用与标点**

- 正文引用编号公式写“代入式 1.3”（`@eq-…`），不写“式（1.3）”；图表引用写 `@fig-…`、`@tbl-…`，由渲染器自动生成“图 N”“表 N”，源文不加量词（§5.2）。

### 8.9 图表、题注与表格单元格

- 题注末尾**不加冒号、不加句号**；题注内部分句用逗号，并列用分号。
- 表格**单元格末不加标点**；需分句时单元格内用逗号、并列用分号，末项不加标点。
- 表注（表下说明）按正文规则加句末标点；图注即题注，不加。
- 单元格内的数学式遵守 §8.8(b) 的式内规则，但式末**不加标点**（单元格末不加标点优先，此为 §8.8(a) 的登记例外）。

### 8.10 列表与条目

- 无序列表：条目为短语时末不加标点；为完整句时加句号；整组并列时分号＋末项句号（与 §8.4 同）。
- 有序列表用 `1.` `2.`（渲染器语法要求半角点与空格）；行文内序号用全角括号（1）（2），不用 `(1)`、`1、`。
- 列表项不得为空或仅含标点；列表与其上一段之间留空行。

### 8.11 代码、链接与文献

- 行内代码与代码块内的标点一律保持原样（多为半角），不受本节约束。
- URL、DOI 内的 `: / . -` 不改写；句末标点放在链接**之外**。
- 参考文献条目按 GB/T 7714—2015 的半角标点体系，由 CSL 生成，不手改（§11）。

### 8.12 机器可查与人工复核

脚本覆盖：直角引号与半角引号、引号配对与方向、引号前空格、连续或重复标点、中文邻接半角标点、汉字与标点间空格、显示公式末标点（必须以半角 `.`、`,`、`;` 收束，落点按公式形态判定）、式末禁用全角标点、公式块内空行、公式内中文标点、题注冒号与句号、表格单元格末标点、行文序号形式、破折号连用、范围号写法、全角数字字母。

人工复核（脚本不可判）：括注句号归属（句内或整句）、引号内外句号、**式末标点的句读归属（该收 `.` 还是 `,`）**、公式引导语是否读得通、列表末标点是否与条目性质匹配。

## 9 图

- 路径 `images/<名>.png`（相对章文件）；**每图必有** `{#fig-<名>}` 标签与 `width=`。
- **题注不超过 40 字的简要名**：图目录自明即可；细节（推导、读法、参数）移入图前后正文；可留在题注的只有图例性信息（如“左 $K=c$，右 $K=\infty$”“点线为无实像段”）。
- `width` 按纵横比取 60% 至 100%（宽图取满，方形图收窄）。
- 配图脚本与 PNG 同名同目录；`savefig` 必须 `dpi=200, facecolor="white", bbox_inches="tight", pad_inches=0.03`，否则图与题注之间会出现大片白边；重跑后白边应不超过 20 px。
- 数学式排版核验不信 PDF 文本提取（字形顺序乱），用页面渲图目视。

## 10 表

- Markdown 管道表；标签 `{#tbl-<名>}`；表题行 `: 表题 {#tbl-<名>}`。
- 列数克制（不超过 5 列；拥挤时删冗余列，不靠缩字号硬塞）。
- **列宽由分隔行的破折号比例控制**：分隔行 `|------|----------------|` 即 6:16。要调某张表的列宽，改分隔行的破折号长短，不改内容；分隔行长短悬殊会压垮窄列（§1.3）。
- 短表保持 longtable（改浮动 table 会破坏续表头与交叉引用）。
- 关键词索引表由脚本生成（含局部行距设置），不手改。

## 11 参考文献

- 引用 `[@key]`；样式 GB/T 7714-2015（numeric）。
- **DOI 断行不在 `.bib` 里修**：在 `preamble.tex` 的参考文献环境内局部把 `\href` 的显示文本交给 `\nolinkurl`；补丁内层参数须写 `##1 ##2`（嵌套定义）。全局改 `\href` 会破坏 hyperref 的 catcode，禁止。
- 借用结果标注原始出处，不称原创；“借用的”与“新增的”在全书导览登记。

"$PY" - <<'PY'

    if b"\r" in raw:

    if raw.startswith(b"\n"):
        print("空首行:", f)
    for i, line in enumerate(raw.split(b"\n")):

## 14 常见问题对照

| 现象 | 处置规则 |
|------------------------------------------------|------------------------------------------------------------|
| 汉字整篇不出字形，只剩西文与数字 | §1.3：渲染链未指定含 CJK 字形的字体；抽取文本统计汉字数，为 0 即确诊 |
| 表格两列文字叠在一起 | §1.3：分隔行破折号长短悬殊，窄列被压到百分之一量级 |
| 引用示例被当成真引用、编译中断 | §1.3：示例字面必须放进行内代码 |
| “换指定”写成“换场景” | 指定互换＝曲线不动、只把参与方配到另一条曲线；换场景＝整段登记换掉 |
| 四舍五入的结果仍用 `=` | §7.2：先判“右侧是不是精确值”；体例检查与算术核验分开跑 |
| 同一处既写“约”又写 `\approx` | §7.2：散文用“约”，公式用 `\approx`，一个小句只留一个标记 |
| nabla 出现假粗体或箭头 | §7.1：`\boldsymbol{\nabla}` 在本书字体下不粗，`\vec\nabla` 出箭头；一律裸写 |
| `\mathbf{\xi}` 直接消失 | §7.1：unicode-math 下 `\mathbf` 只对拉丁字母有效，希腊向量用 `\boldsymbol` |
| 全局 `\href` 补丁毁掉 hyperref | 补丁只在参考文献环境内；嵌套参数用 `##1` |
| 指向无编号章的 `@sec-` 无法解析 | §2.1：无编号章不可交叉引用，用纯文字 |
